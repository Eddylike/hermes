# Eddys Hermes

Persönliche Konfiguration für [Hermes Agent](https://github.com/NousResearch/hermes-agent) (Nous Research).

| Datei/Ordner | Inhalt |
|---|---|
| `config.yaml` | Hauptkonfiguration (Modelle, Provider, Tools) |
| `SOUL.md` | Persönlichkeit / System-Prompt |
| `skills/` | Skills |
| `memories/`, `hooks/`, `cron/` | Eigene Memories, Hooks, geplante Jobs |
| `backups/` | Config-Backups |
| `.env` | API-Keys – **nur lokal, nie committen** |

Live-Installation liegt unter `%LOCALAPPDATA%\hermes` (Runtime, Caches, Agent-Code).
Dieser Ordner ist die versionierte Kopie der eigenen Einstellungen.
